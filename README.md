# 일본어 어휘 퀴즈

일본어 설명문에서 선별한 표현과 기초 어휘를 복습하는 확장형 웹 퀴즈입니다. 1회차 단어 묶음은 활용형과 문법 조합을 걷어 내고 기본형 중심의 100개로 정리했습니다.

- 일본어 → 뜻 객관식 / 뜻 → 일본어 직접 입력 / 혼합 모드
- 10문제 / 20문제 / 전체 100문제 출제
- 부사, 고유어 동사, 훈독 복합어, 일본 철도 어휘 수록
- 정답 해설과 읽기·분류 표시
- 점수, 정답률, 연속 정답 집계
- 오답만 다시 풀기
- 객관식은 숫자키 1-4로 선택, 직접 입력은 Enter로 채점
- 채점 후 Enter로 다음 문제 이동
