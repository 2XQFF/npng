# 일본어 어휘 퀴즈

일본어 설명문에서 선별한 표현을 복습하는 확장형 웹 퀴즈입니다. 현재 단어 묶음 96개는 일본어 위키백과 「山手線」과 「東京」 문서를 출처로 삼았습니다.

- 일본어 → 뜻 / 뜻 → 일본어 / 혼합 모드
- 10문제 / 20문제 / 전체 96문제 출제
- 부사, 고유어 동사, 훈독 복합어, 일본 철도 어휘 수록
- 정답 해설과 읽기·분류 표시
- 점수, 정답률, 연속 정답 집계
- 오답만 다시 풀기
- 숫자키 1-4로 답 선택, Enter로 다음 문제 이동
